Build a text pipeline once, then run it on anything you select.

String Utility Belt brings 242 text and developer utilities to Chrome, and something most text tools can't do: whole pipelines. Chain steps on stringutilitybelt.com (trim every line, lower-case it, drop duplicates, sort), save the pipeline to the extension in one click, and run every step on any selection from the right-click menu. Single utilities are there too: decode Base64, format JSON, change case, generate a hash, and more.

WORK WHERE YOUR TEXT IS

Select text on a page, right-click, and choose String Utility Belt. In supported editable fields, the result replaces your selection. If nothing is selected in a supported text field, the utility works on the whole field. For ordinary page text, the extension attempts to copy the result and keeps it available in the popup.

USE THE TOOLBAR POPUP

Paste text, choose a utility, adjust the available settings, and click Run. Review the result and copy it when you are ready. Set JSON indentation, choose a case style, pick a hashing algorithm, and more.

TOOLS FOR DAILY DEVELOPMENT

• Encode and decode Base64 and URLs.
• Decode JWT contents for inspection.
• Pretty-print JSON and work with data formats.
• Change case, trim whitespace, and transform lines of text.
• Generate hashes, including SHA-256, SHA-384, and SHA-512.
• Explore utilities for numbers, dates, colors, analysis, and more.

MAKE THE RIGHT-CLICK MENU YOURS

Start with ten useful favourites, then put them in the order you want, remove the ones you don't use, and add others by searching the Options page by name, identifier, tag, or category. Right-click actions use each utility's default settings; the popup exposes supported settings for individual runs.

SAVED PIPELINES, ONE CLICK AWAY

Build a multi-step pipeline on stringutilitybelt.com, with a preview after every step, steps that run on each line, and branches. Send it to the extension with "Save to extension", or paste its share link on the Options page. Each saved pipeline becomes one item in your right-click menu and in the toolbar popup, and runs every step with the settings it was saved with. Saving again under the same name updates it. Rename, reorder, or delete pipelines on the Options page.

LOCAL PROCESSING, WITH A CLEAR HANDOFF

Transformations run locally in the extension. It stores the last result locally so it can be reused in the popup, and menu preferences and the app URL use Chrome's sync storage. Choosing “Open selection in String Utility Belt” opens the configured website with your selected text in the URL. The default destination is stringutilitybelt.com.

No account is required to use the extension. String Utility Belt is open source under the MIT license.
